# Prawler

This project is a **web crawler** developed as part of a **university course project**. The purpose of this crawler is to developing a semantic search engine as a final project to Text mining course.

## Disclaimer

This crawler was created **strictly for educational purposes**. It is designed to explore publicly accessible web pages

The crawler is **not intended to harm websites, overload servers, or violate any website policies**.

## Website Owner Notice

If you are a **website owner or administrator** and you notice that this crawler:

- Is causing unusual traffic
- Is behaving unexpectedly
- Should not crawl your website

please feel free to contact me. I will be happy to **investigate the issue, adjust the crawler, or blacklist your website** from future crawling.

## Responsible Crawling

The crawler attempts to behave responsibly by:

- Limiting request frequency
- Avoiding excessive traffic
- Respecting standard crawling practices when possible

However, as this is an experimental academic project, unexpected behavior may occasionally occur.
